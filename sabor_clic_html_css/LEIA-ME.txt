SABOR & CLIC — VERSÃO INTEGRADA

Como abrir:
1. Extraia o arquivo ZIP inteiro.
2. Abra index.html no navegador.
3. Na página inicial, escolha Entrar ou selecione um perfil.
4. Cada perfil possui um menu lateral próprio e páginas mais objetivas.

Estrutura:
- index.html: página inicial com a frase “Seu sabor favorito, a um clique.” e acesso aos perfis.
- cliente/index.html: cardápio, carrinho, finalização, pedidos e perfil.
- empreendedor/index.html: painel, produtos, pedidos, clientes, relatórios, avaliações e configurações.
- cozinheiro/index.html: painel de produção e histórico.
- administrador/index.html: usuários, restaurantes, catálogo, relatórios e locação de equipamentos.
- styles.css: identidade visual compartilhada e layout responsivo.

Observações importantes:
- Este é um protótipo navegável de interface em HTML5 e CSS3.
- Menus e links navegam entre páginas/seções.
- Dados, login real, carrinho dinâmico, salvamento de cadastros e atualização dos pedidos ainda são demonstrativos e precisarão de JavaScript e integração com a API Flask/banco de dados.
- As imagens são carregadas de fontes externas; é necessário estar conectado à internet para visualizá-las.
